lavagna round [DIR] < round.md
Wait for the next feedback batch; no timeout. Esc interrupts.
DIR supplies round.md and files under DIR/<question-id>/. Each question owns its
resources. A bare question title plans it without presenting an artifact.
Stdout: one JSON result grouped by question. URL/status: stderr. Large outcomes
are deferred; read them with lavagna feedback SUBMISSION [--question ID|--overview|--all].
Use lavagna feedback --help for selectors and retained reads.
An unanswered question is not approval. Feedback is not completion: continue with
round; only close ends the phase. Close deletes the retained question artifacts.

Minimal question:
# Where do we store state? {id="storage"}
## Capire
Per-session files keep the state local.
## Decidere
- [file] Per-session files {recommended}
- [db] Database

Several questions may be included in one call. Use ## Capire, ## Confrontare,
and ## Decidere in that order.
Lavagna keeps the phase's questions: later calls send only what changes. A new
question opens the next round; a whole question with a known id replaces it.
::: reply [ID] posts a message, ::: settled ID [OPTION] closes a question with
its Why as body; close both with :::. An empty call only resumes waiting.
Current question versions fit 16 MiB per phase; one message fits 32 KiB.
After close, expiry or an upgrade the phase is empty: send complete questions.
