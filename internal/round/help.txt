lavagna round [--reuse rN] [DIR] < round.md
Wait for one feedback batch; no timeout. Esc interrupts.
DIR supplies round.md and local assets. --reuse keeps rN's content snapshot;
supply only new # Decidere on stdin (no DIR), never inherited choices.
Stdout: one JSON result. URL/status: stderr. Small feedback is inline;
deferred:true means more data is retained; see lavagna feedback --help.
Omitted/cleared choices are unanswered, not approved.
Feedback is not completion: continue with round; only close ends the phase.
Read needed feedback/images before close: it deletes phase data.

Minimal round (multiple questions allowed; choices are optional):
# Decidere
## Where? {id="storage"}
- [file] Per-session files
- [db] Database

Add # Capire, then # Confrontare before # Decidere when useful, not by default.
Text: paragraphs, ##/### headings, - lists, **bold**, `code`.
Anchor content with {ref="Name"}; comments return that name, or null.
More: lavagna round --help grammar (components, tables, excerpts, HTML, assets).
