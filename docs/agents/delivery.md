# Delivery policy

- Default mode: `pr`.
- Integration target and PR base: `taekwondodev/lavagna`, remote `origin`, branch `main`.
- PR source: branches on `origin`.
- Required verification: use the relevant checks in [Development](../DEVELOPMENT.md#verification).

Before selecting the route or preparing a branch, read the shared delivery reference supplied by `implement` (`references/delivery.md`). This policy selects the route; it does not itself authorize publication or merging.
